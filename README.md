# Rela

Rela 是面向实验室成员的 Windows 网络客户端。连接后，你可以访问实验室的服务器、网页和文件存储，并在一个窗口里查看连接状态和资源入口。

使用前，请向实验室管理员领取 **credential 连接凭据**。它用于加入实验室网络；服务器的登录账号和密码仍由管理员另行提供。

## 下载与安装

前往 [Releases 页面](https://github.com/Starxy/Rela/releases)下载适合你的版本。目前提供 Windows 64 位版本，无需登录 GitHub。

| 版本   | 下载文件                       | 使用方式                                            |
| ------ | ------------------------------ | --------------------------------------------------- |
| 安装版 | `Rela_<版本>_x64-setup.exe`    | 双击安装，按提示完成后打开 Rela，适合日常使用。     |
| 绿色版 | `Rela_<版本>_x64-portable.zip` | 完整解压到本地有写入权限的文件夹，双击 `Rela.exe`。 |

绿色版请保留包内的全部文件，不要直接在压缩包中运行。如果提示缺少 WebView2，请安装 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 首次连接

1. 打开 Rela，等待默认网络配置加载完成。
2. 点击右上角的**设置**，进入**网络**页。
3. 在 **credential 凭据**中粘贴管理员提供的内容，点击**保存**。网络名称和连接节点通常保持默认即可。
4. 回到首页，打开连接开关。首次连接出现 Windows 管理员授权提示时，确认后继续。
5. 等待状态变为**已连接**，再打开**实验室资源**查看可用入口。

同一 Windows 用户后续的日常连接、断开和重连通常无需再次授权。更新软件或更改网络设置、凭据、设备名称后，可能需要重新授权。

## 日常使用

- **连接或断开**：使用首页的开关。连接需要时间时，首页会显示正在等待的原因。
- **访问资源**：打开“实验室资源”，查看地址与可用状态。资源内容由管理员维护；“未检测”表示尚未完成检查。
- **查看状态**：首页显示分配给本机的地址和连接情况，点击连接详情可查看更多信息。
- **检查问题**：打开“诊断”，查看检查结果；需要协助时可以导出诊断摘要交给管理员。

最小化或关闭窗口会将 Rela 隐藏到系统托盘，网络连接会继续保持。点击托盘图标可恢复窗口，右键选择“退出 Rela”可退出界面。**退出界面也会保留连接；需要断开时，请先关闭首页开关。**

目前需要手动打开软件并连接，暂不支持开机自动连接。

## 设置与配置更新

通常只需填写连接凭据，其他选项按管理员提供的说明调整。校园网关可以留空，不影响正常连接。

Rela 会在启动时获取管理员维护的网络配置和资源列表。如果你手动修改了网络名称或连接节点，自动获取会暂停；点击**更新线上配置**后，会用线上内容替换网络名称、连接节点和资源列表，并恢复自动获取。

已保存的凭据不会重新显示，输入框留空会保留现有凭据。更换网络时，请同时换用对应凭据。需要删除凭据时，先断开连接，再点击**清除凭据**。**恢复默认设置也会清除已保存的凭据。**

## 更新软件

在 [Releases 页面](https://github.com/Starxy/Rela/releases)查看并下载新版本。软件提示发现新版本时，也可以点击**前往 GitHub 下载**。

- **安装版**：先从系统托盘退出 Rela，再运行新版安装包。
- **绿色版**：先从系统托盘退出 Rela，备份 `data` 文件夹，再用新版完整包替换程序文件，保留原有的 `data` 和 `portable.txt`。

绿色版的设置保存在解压目录中的 `data` 文件夹。移动目录前请退出 Rela；换电脑或换 Windows 用户后，需要重新填写连接凭据。

## 常见问题

| 遇到的问题                   | 可以先这样处理                                                   |
| ---------------------------- | ---------------------------------------------------------------- |
| 默认配置加载失败             | 检查电脑是否可以访问互联网，再到设置中点击“更新线上配置”。       |
| 提示填写连接凭据             | 在设置中粘贴管理员提供的 credential 并保存；确认它属于当前网络。 |
| 一直显示“正在连接”或连接失败 | 查看首页的提示，打开“诊断”；仍无法连接时，将诊断摘要交给管理员。 |
| 已连接，但某个资源无法访问   | 确认资源地址和账号是否正确，并联系管理员检查该资源是否开放。     |
| 关闭窗口后找不到 Rela        | 在任务栏的系统托盘中找到 Rela 图标，点击即可恢复。               |
| 换用户后无法读取凭据         | 使用当前 Windows 用户重新填写管理员提供的连接凭据。              |

需要反馈软件问题时，可以在 [Issues](https://github.com/Starxy/Rela/issues)中提供版本号、问题出现的步骤和界面提示。请勿公开连接凭据、密码或其他私密信息。

## 移除软件

安装版可以通过 Windows 的“已安装的应用”卸载；绿色版可以在退出 Rela 后删除解压目录。卸载或删除界面程序会保留本机的网络服务。

如果需要彻底移除网络服务，先退出所有 Rela 界面，再以管理员身份运行程序目录中的 `Remove-Network-Service.cmd`，按提示输入 `REMOVE`。这会断开连接，并影响本机其他 Rela 副本，请确认它们也不再需要该服务。
