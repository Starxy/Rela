# Rela：基于 EasyTier 的极简实验室远程访问客户端

> **Rela** 是一个面向实验室成员的轻量远程访问客户端。  
> EasyTier 作为底层网络引擎，Rela 负责设备接入、连接控制、状态展示、资源访问和故障诊断。

---

## 1. 项目定位

Rela 不是 EasyTier GUI 的简化复刻，而是一个面向普通实验室成员的“实验室远程资源入口”。

普通用户只需要理解：

- 连接 / 断开
- 当前 VPN 是否正常
- 校园网关是否可达
- GPU、NAS、Jupyter 等实验室资源是否可访问

以下 EasyTier 概念默认全部隐藏：

- Network Name
- Network Secret
- Initial Peer
- Listener
- TUN
- P2P
- NAT
- Hole Punching
- Relay
- Subnet Proxy
- Exit Node
- Route
- ACL

产品目标：

```text
打开 Rela
   ↓
点击“连接”
   ↓
实验室资源可访问
```

管理员继续通过 EasyTier Web Console 管理网络、节点、凭据和高级网络配置。

## 2. 产品名称

**Rela**

名称来源于 Relay，但不直接使用网络技术术语本身。

推荐命名：

```text
桌面客户端：Rela
本地后台服务：rela-agent
核心网络引擎：easytier-core
```

CLI / 内部命令可统一：

```bash
rela connect
rela disconnect
rela status
rela doctor
```

## 3. 技术方案

### 3.1 技术栈

桌面端采用 **Tauri**。

推荐技术组合：

```text
Tauri
├── Frontend: React + TypeScript
├── Native Backend: Rust
├── EasyTier Core: Sidecar / External Binary
└── OS Integration:
    ├── Windows Service
    ├── macOS LaunchDaemon / LaunchAgent
    └── Linux systemd
```

建议第一阶段优先支持：

```text
Windows 11
```

稳定后再补：

```text
macOS
Linux
```

## 4. 总体架构

```text
┌─────────────────────────────────┐
│ Rela                            │
│ Tauri Desktop Application       │
│                                 │
│ React + TypeScript              │
└───────────────┬─────────────────┘
                │ Tauri Command / IPC
                ▼
┌─────────────────────────────────┐
│ Rela Native Layer               │
│ Rust                            │
│                                 │
│ - Core 生命周期管理             │
│ - 状态查询                      │
│ - 健康检查                      │
│ - 凭据管理                      │
│ - 日志管理                      │
│ - 系统集成                      │
└───────────────┬─────────────────┘
                │
                │ Local IPC / Service Control
                ▼
┌─────────────────────────────────┐
│ rela-agent                      │
│ Elevated Background Service     │
│                                 │
│ - 启停 EasyTier                 │
│ - TUN / 路由相关高权限操作      │
│ - 自动重连                      │
│ - 配置拉取                      │
└───────────────┬─────────────────┘
                │
                ▼
┌─────────────────────────────────┐
│ easytier-core                   │
│ Bundled Sidecar                 │
└───────────────┬─────────────────┘
                │
                ▼
        EasyTier Virtual Network
```

核心原则：

> GUI 不直接持有管理员权限。

Rela 前端只调用 Rust Native Layer；真正需要管理员权限的 EasyTier Core 管理工作交给 `rela-agent`。

## 5. Tauri 侧职责

### 5.1 前端

只负责：

- 连接 / 断开按钮
- 当前连接状态
- 延迟
- P2P / Relay 简化状态
- 实验室资源状态
- 诊断结果
- 设置
- 日志导出

前端不直接接触：

```text
network_secret
EasyTier CLI 参数
系统路由
TUN
管理员权限
```

### 5.2 Rust Native Layer

负责提供 Tauri Commands，例如：

```text
get_status
connect
disconnect
reconnect
run_diagnostics
get_resources
open_resource
export_logs
get_version
```

调用关系：

```text
Frontend
   │ invoke("get_status")
   ▼
Rust
   │
   ├── 查询 rela-agent
   ├── 查询 EasyTier RPC
   └── 返回结构化状态
```

返回给前端的数据应是业务语义，而不是 EasyTier 原始结构。例如：

```json
{
  "connected": true,
  "virtual_ip": "10.144.144.23",
  "gateway": "online",
  "latency_ms": 24,
  "connection_type": "direct",
  "resources_available": 3,
  "resources_total": 3
}
```

## 6. EasyTier Core 集成方式

EasyTier Core 不重新实现。

Rela 随安装包附带经过验证的固定版本：

```text
easytier-core
```

不建议运行时直接下载 `latest`。

推荐版本关系：

```text
Rela 0.1.x
└── EasyTier Core 2.6.x
```

升级 Rela 时再统一升级和验证 EasyTier Core。

### 6.1 Sidecar

EasyTier Core 作为 Tauri External Binary / Sidecar 分发。

目录示意：

```text
rela/
├── src/
├── src-tauri/
│   ├── src/
│   ├── binaries/
│   │   └── easytier-core
│   └── tauri.conf.json
└── package.json
```

不同平台构建时分别携带对应架构的 EasyTier Core。

## 7. 后台服务 rela-agent

### 7.1 为什么需要 Agent

不建议：

```text
Rela GUI
   ↓
直接启动 EasyTier Core
```

因为会产生：

- GUI 关闭后 VPN 退出
- 每次连接都可能触发 UAC
- 管理员权限长期留在 GUI
- 休眠 / 网络变化恢复困难
- 开机自动连接不好处理

推荐：

```text
Rela GUI
   ↓
rela-agent
   ↓
easytier-core
```

### 7.2 Agent 职责

`rela-agent` 负责：

- 安装 / 更新 EasyTier Core
- 启动 EasyTier Core
- 停止 EasyTier Core
- Core 异常恢复
- 网络变化后的健康检查
- 开机自动启动
- 自动连接
- 本地凭据读取
- EasyTier Config Server 接入
- RPC 状态读取
- 日志收集

## 8. 配置管理

Rela 不允许普通成员手工配置 EasyTier 网络。

客户端本地只保存：

```text
Config Server URL
Machine ID
Device Credential
User Preferences
```

实际网络参数由管理员控制：

```text
EasyTier Web Console
        │
        ▼
Config Server
        │
        ▼
Rela / EasyTier Core
```

管理员负责：

- Network Name
- Network Secret / Credential
- Initial Peer
- P2P 策略
- Relay
- Subnet Proxy
- ACL
- Route

普通成员无需接触。

## 9. 设备注册

首次启动推荐流程：

```text
欢迎使用 Rela

姓名
设备名称
邀请码

[加入实验室网络]
```

后台流程：

```text
邀请码
   ↓
Rela 注册 API
   ↓
验证成员
   ↓
绑定 Machine ID
   ↓
生成 / 下发 Device Credential
   ↓
保存到系统安全存储
   ↓
连接 EasyTier Config Server
   ↓
进入实验室网络
```

推荐一人一设备一个 Credential。

不建议：

```text
全组共享 network_secret
```

这样成员离组或设备丢失时，可以单独撤销设备权限。

## 13. 一键诊断

提供：

```text
[运行诊断]
```

自动检查：

1. rela-agent 是否正常
2. EasyTier Core 是否运行
3. TUN 是否创建
4. 是否获得 Virtual IP
5. Initial Peer 是否可达
6. 是否发现 Campus Gateway
7. 当前是 P2P 还是 Relay
8. Gateway RTT
9. 目标服务器端口是否可达
10. DNS 是否异常
11. 默认路由是否异常

输出不要直接显示原始日志。

例如：

```text
诊断结果

✓ Rela 后台服务正常
✓ EasyTier Core 正常
✓ 已获得虚拟 IP
✓ 已连接公网节点
✓ 已发现校园网关
! 当前通过中继连接，延迟较高
✓ GPU01 SSH 可访问

整体状态：可以正常使用
```

## 15. 自动重连

需要处理：

```text
Wi-Fi 切换
有线 / 无线切换
手机热点
系统休眠
系统唤醒
网络短暂中断
```

逻辑：

```text
系统网络发生变化
        ↓
等待网络稳定
        ↓
检查 rela-agent
        ↓
检查 EasyTier Core
        ↓
检查 Gateway
        ↓
必要时 restart core
```

底层 Peer 重连和 P2P 建立仍交给 EasyTier。

## 16. 安全设计

### 16.1 凭据

优先：

```text
Device Credential
```

而不是：

```text
Shared Network Secret
```

### 16.2 本地存储

Windows：

```text
Windows Credential Manager / DPAPI
```

macOS：

```text
Keychain
```

Linux：

```text
Secret Service
```

### 16.3 RPC

EasyTier RPC 仅允许：

```text
127.0.0.1
```

禁止：

```text
0.0.0.0
```

### 16.4 权限

GUI：

```text
普通用户权限
```

Agent：

```text
系统服务权限
```

两者通过受限 IPC 通信。

## 23. 产品边界总结

Rela 的职责：

```text
成员接入
连接控制
状态展示
资源入口
故障诊断
```

EasyTier 的职责：

```text
虚拟网络
P2P
NAT Traversal
Relay
Route
Subnet Proxy
```

EasyTier Web Console 的职责：

```text
网络配置
节点管理
Credential
ACL
管理员高级配置
```

最终形成：

```text
                 EasyTier Web Console
                     管理员控制面
                          │
                          ▼
Rela ───────────── EasyTier Core
成员客户端              网络数据面
   │
   ▼
GPU / NAS / Jupyter / 校园服务器
```

> **Rela 的价值不在于提供更多网络参数，而在于让实验室成员不需要知道这些参数。**
