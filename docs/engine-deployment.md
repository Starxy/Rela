# 随包引擎部署与配置切换

此模块用于用户连接、重连和断开时管理随包网络引擎与服务配置。软件由用户手动下载与安装，网络引擎在连接操作中部署。Windows 服务、UAC 和真实 TUN 验收仍需独立测试机。

## 版本来源

- 随包版本：通过嵌入的完整文件摘要校验后读取固定 Core 版本。
- 已部署版本：管理员成功部署后写入受保护的部署记录；GUI 通过 SCM 的只读描述元数据读取其公开版本副本。没有记录时显示未知，不用随包版本代替。
- 运行版本：SCM 确认专用服务运行、程序路径属于 Rela 后，从实际 node RPC 的 version 字段读取，并核对固定 instance_id。
- 引擎修订：config/easytier-version.json 中单调递增的 engine_revision，避免把开发版提交哈希按字典序当作版本先后。相同修订不得对应不同版本或文件摘要。
- 部署所属 Rela 版本：阻止低版本副本重写高版本副本的引擎或运行配置；断开和读取不受此限制。

## 历史客户端隔离

旧实现始终覆盖 ProgramData/Rela/engine。新实现迁移到 engine-v2，并通过官方 CLI 更新已核对的固定服务路径与工作目录。历史客户端的服务路径检查会拒绝操作新位置，防止没有版本守卫的旧程序降级服务。只接受 engine 与 engine-v2 两个精确的服务程序路径，不接受任意程序或参数。

## 切换事务

1. 持有机器服务控制锁，恢复未完成事务，再校验请求、随包资产和已有部署版本。
2. 在受保护目录准备完整引擎、部署记录和新 TOML；此时保留现有连接。
3. 原子写入事务日志，记录此前服务是否存在/运行、原路径、文件存在性、旧配置能否安全重启。
4. 暂停普通用户启停权限并撤回公开配置确认，停止服务并等待退出；把原引擎和 TOML 移到事务备份，将暂存内容移到固定新位置。
5. 通过官方 CLI 安装或切换专用服务路径和工作目录，启动并验证服务状态、RPC 实例和实际版本。
6. 验证通过后发布版本与运行配置摘要并写提交标记，再清理事务备份，给发起请求的 Windows 用户授予服务查询与启停权限。网络连接仍由真实节点与 TUN 状态判定。
7. 失败或重启后发现未提交日志时，停止新服务、恢复原文件、服务路径、描述与权限；仅当旧配置使用 credential 时允许恢复此前运行状态。旧主密码配置不自动启动或回退认证。

所有路径由程序生成，拒绝重解析点与意外目录内容；日志不含 credential，备份 TOML 保持管理员/系统 ACL。取消 UAC 前不会发生服务切换。恢复失败时保留日志和备份，报告需要恢复，不继续覆盖。

## 日常启停与授权

首次部署、引擎或实际运行配置变化时使用一次性提权助手。服务注册通过固定 Core CLI 的 `--core-args` 传入受限启动参数。注册、端口、启动校验或文件失败时，界面保留具体受控原因及恢复结果，不转发可能含凭据的 CLI 输出。

部署成功后只给请求文件的 Windows 所有者授予 `SERVICE_START`、`SERVICE_STOP` 和查询权限；即便 UAC 使用另一个管理员账号，启停权限仍属于发起请求的用户。服务程序、TOML、配置变更、删除、权限与所有者修改继续限制为管理员和系统。权限范围依据 [Windows 服务权限](https://learn.microsoft.com/en-us/windows/win32/services/service-security-and-access-rights)。

普通连接和重连先核对专用服务路径、受限参数、已确认的引擎版本和配置摘要，相同配置直接通过 SCM 启停，使用随包 CLI 核对实际 RPC 实例与版本。已运行时不重复部署；未安装或已停止时断开不弹 UAC。旧部署缺少摘要或当前用户缺少启停权限时，需要一次授权建立新记录；参数、凭据或设备名称变化时重新授权。切换前撤回确认并暂停普通启停，失败恢复原权限；已提交的事务恢复时重新核对配置摘要。

## 验证

文件事务与故障注入测试覆盖准备、备份、替换、启动、提交和清理边界，并保留原配置字节；版本测试覆盖旧副本、同修订内容变化和未知版本。它们仅证明算法与文件行为，不能代替独立 Windows 服务/TUN、UAC 取消和手动安装新版后的服务验收。

当前已接入连接、重连和断开流程；协议 v9 与设置页分开展示三种版本。文件事务测试覆盖首次部署、引擎切换、旧目录迁移、中断与恢复重试、文件占用、版本守卫和篡改拒绝。权限、SCM 切换、UAC 与真实断网恢复仍待独立机器验收。

上游官方 CLI 的安装命令会更新已有 Windows 服务及其工作目录；固定开发版源码已检查，历史 2.6.4 的同一行为可见 [上游服务实现](https://github.com/EasyTier/EasyTier/blob/v2.6.4/easytier/src/service_manager/mod.rs)。
