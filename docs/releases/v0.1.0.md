# Rela 0.1.0

Rela 的首个测试版本，面向需要连接实验室网络、访问共享资源的 Windows 用户。

## 下载

- **安装版**：`Rela_0.1.0_x64-setup.exe`，适合日常使用。
- **绿色版**：`Rela_0.1.0_x64-portable.zip`，完整解压后运行 `Rela.exe`。
- **校验文件**：`SHA256SUMS.txt`，用于核对下载文件是否完整。

两个版本均适用于 Windows 64 位系统。绿色版需要电脑已安装 [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 可以做什么

- 使用管理员提供的 credential 凭据连接实验室网络。
- 查看连接状态、分配地址、节点延迟和实验室资源入口。
- 获取管理员维护的网络配置与资源列表，也可以按需调整本机设置。
- 将窗口收起到系统托盘，在后台保持连接。
- 查看连接诊断，并导出摘要供管理员排查问题。

## 开始使用

打开 Rela，等待默认配置加载完成，在“设置 → 网络”中粘贴管理员提供的 credential 并保存，然后打开首页的连接开关。首次连接需要 Windows 管理员授权。

最小化、关闭窗口或从托盘退出界面后，网络连接仍会保留。需要断开时，请先关闭首页开关。目前需要手动连接，暂不支持开机自动连接。

已有绿色版用户更新时，请先从托盘退出 Rela，备份并保留原 `data` 文件夹和 `portable.txt`，再替换完整程序文件。

这是早期测试版本，独立 Windows 环境下的完整安装、权限和升级验收尚未完成。遇到问题时，请附上版本号、操作步骤及诊断摘要，勿公开连接凭据或密码。
