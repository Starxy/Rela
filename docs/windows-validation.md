## 随包引擎部署验收（待独立机器）

- 对比设置页随附、已部署、正在运行三个版本；运行版本来自实际 RPC。
- 首次部署、旧 engine 迁移至 engine-v2、同版本重连、手动换新版后的引擎切换；核对服务工作目录与固定 SCM 参数。
- 旧副本重连不得降级；停止和读取仍可用。
- 引擎与配置切换中断后再次操作，核对实际服务、文件和配置；恢复失败保留部署日志与备份。
- 旧密码配置不自动恢复连接，断开操作中的恢复不重启连接。
- 普通用户不能改写受保护的部署记录、资产与 TOML；拒绝不可信路径。
